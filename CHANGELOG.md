# Changelog

## [0.2.0] - 2026-08-11

### Added

- Mutable shared player states through `canSet()` and `setActive(...)`
- `JustCoreApi.setState(...)` and `canSetState(...)`
- Native vanish-state integration for Just Vanish and Just Essentials
- Central audit events consumed by Just Essentials and its Discord integration

## [0.1.0] - 2026-08-09

### Added

- Initial server-side Just ecosystem API
- Module and player-state provider registries
- Persistent JSONL staff-action audit log
- Public `StaffActionEvent`
- Diagnostic commands
